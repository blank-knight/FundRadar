## 一、为什么转

### FundRadar 现状的瓶颈
1. **监管风险**：没有投顾牌照推买卖信号，法律灰色地带
2. **同质化**：信号工具太多，差异化不够
3. **变现弱**：用户付费意愿低（信号准不准存疑，且可替代品多）

### 数字分身教育的优势
1. **合规**：教知识 ≠ 推荐股票，法律风险低
2. **壁垒高**：完整交易系统搭建经验是稀缺内容，不是调个 API 就能复制的
3. **变现清晰**：课程/资料/会员，数字分身自然引导转化
4. **现有资产可复用**：FundRadar 的爬虫+LLM+信号代码 = 最好的实战教学案例

## 二、产品定位

**一句话**：用 AI 数字分身教小白从0搭建自己的 A股交易系统。

**目标用户**：
- 有点编程基础（或愿意学）的散户
- 不满足于"听别人推荐"，想自己搞明白交易系统的人
- 量化入门者

**核心价值**：
- 不是给你鱼（信号），是教你做鱼竿（交易系统）
- 数字分身 24h 在线，个性化教学，按你的水平调整
- 每个知识点都有 FundRadar 真实代码佐证

## 四、课程体系设计

### 模块化，每个模块可独立售卖

**Module 0: 交易系统认知（免费引流）**
- 什么是交易系统？为什么需要？
- 交易系统的五大组件
- FundRadar 案例展示：一个完整系统的长什么样

**Module 1: 数据采集层（¥99）**
- Python 爬虫基础
- A股数据源全解析（akshare/东财/同花顺）
- 实战：用 akshare 拉行情数据
- 实战：爬取微博大V观点（FundRadar 真实代码）
- 反爬对抗（频率控制/UA/Cookie）

**Module 2: 信号分析层（¥129）**
- LLM 在交易中的应用
- 用 GLM/GPT 分析新闻情绪
- 博主观点解析（NLP/LLM 方案）
- 多源信号融合（加权策略）
- 实战：FundRadar 六维信号系统拆解

**Module 3: 回测与验证（¥129）**
- 为什么必须回测
- 回测框架选择（backtrader/vectorbt）
- 常见陷阱（过拟合/前视偏差/幸存者偏差）
- 实战：用 FundRadar 历史数据回测

**Module 4: 风控与资金管理（¥99）**
- 仓位管理（凯利公式/固定比例）
- 止损策略
- 最大回撤控制
- 实战：设计自己的风控规则

**Module 5: 系统集成与部署（¥149）**
- 数据库设计（PostgreSQL）
- 定时任务调度（APScheduler）
- Telegram/微信推送
- 实战：部署你自己的 FundRadar

## 五、数字分身人设

### 主分身：「老 K」

- **身份**：10年A股老兵+全栈工程师，做过量化、管过基金、踩过所有坑
- **性格**：直来直去，不废话，偶尔毒舌但真心为学生好。讲解时喜欢用"说白了就是…"和比喻
- **口头禅**：
  - "别急着写代码，先搞清楚你在解决什么问题"
  - "这玩意儿说白了就是..."
  - "你先跑通再优化，别一开始就整花活"
- **教学风格**：
  - 先讲"为什么"再讲"怎么做"
  - 每个概念配真实代码
  - 主动出练习题
  - 追踪学习进度，落后了会催

### 分身扩展（后期）
- 「小柒」：偏温柔的助教，负责基础概念答疑
- 「铁柱」：硬核技术分身，专攻代码实现

## 九、风险和应对

| 风险 | 应对 |
|------|------|
| 课程内容制作量大 | AI辅助生成框架，核心代码案例已有（FundRadar），用户填充经验 |
| 数字分身教学质量 | RAG + 精心设计的 prompt，关键是知识库质量 |
| 支付合规 | 先用支付宝当面付/微信支付，小额低风险 |
| 引流获客 | 小红书/知乎/B站内容营销，免费 Module 0 做钩子 |
| 竞争（别人也做AI教育） | 壁垒在垂直内容质量+真实代码案例，不是AI本身 |
| "教交易"被质疑割韭菜 | 不承诺收益、用真实代码、FundRadar 信号系统做透明度背书 |
